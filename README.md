# 简历网页 (Interactive Resume)

此项目在 Kevin 个人仓库中新增一个简洁且具有交互效果的个人简历静态页面。页面包含：

- index.html：主页面。
- styles.css：样式文件，包含响应式布局、渐变色与交互样式。
- script.js：前端交互脚本，包含移动导航、滚动 reveal 与项目卡 tilt 效果。

如何在本地运行：

1. 克隆仓库：
   git clone https://github.com/Kevin-kd-23/Kevin.git
2. 进入目录并在本地打开 index.html：
   cd Kevin
   open index.html （或用你喜欢的 HTTP 服务）

说明：
- 这是一个静态页面示例，图片与项目链接为占位，您可以替换为真实内容与图像。
- 若需我把样式调整为浅色主题、添加打印友好样式或整合到 React/Vue 项目中，我可以继续实现。
